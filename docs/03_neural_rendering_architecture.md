## 1. 모델 구조

**등급 (a) — research.nvidia.com/labs/adlr/DLSS5/ 인용**: "single-stage pixel-space
diffusion" 모델. 렌더링 파이프라인 끝단에 붙는 생성형 AI 단계(generative AI stage)로,
게임 엔진이 이미 그린 완성된 컬러 프레임을 입력받아 "그 프레임이 빛에 반응하는 방식을
다시 그림(repaint how that frame responds to light)"(등급 a, back2gaming/NVIDIA 인용
교차 확인).

## 2. 입력 데이터 (컨디셔닝)

**등급 (a)**: G-buffer 정보 — albedo(기본색), surface normal(표면 법선), depth(깊이),
roughness(거칠기), metalness(금속성) — 에 더해 모션 벡터, 시간적 상태(temporal state),
아트 디렉션 값(마스크로 특정 영역만 강도 조절 가능)까지 조건화 입력으로 사용.
개발자는 마스크와 구조/톤 강도(structure/tone intensity)를 조절해 DLSS5가 장면의 어느
부분을 얼마나 바꿀지 제어할 수 있습니다.

## 3. 학습 방법

**등급 (a), 단 설명이 추상적**: "renderer-derived scene property consistency
supervision"(렌더러가 만든 장면 속성과의 일관성 감독)으로 학습되어, 생성 결과가
"저작된 장면(authored scene)"에서 벗어나지 않도록 그라운딩됨. 구체적 손실 함수, 학습
데이터셋 구성, diffusion step 수는 리서치 페이지 요약 수준에서는 확인 안 됨(등급 c,
원본 PDF 재검증 필요).

## 4. 추론 방식

**등급 (a)**: RTX 50 시리즈 GPU에서 **온디바이스** 실행, "기존 게임 파이프라인 내
렌더링 단계로 로컬 실행"(클라우드 추론 아님). 5세대 Tensor Core 타겟.

## 5. "3D-Guided"라는 이름이 오해하기 쉬운 지점

**등급 (a), 원문 명시적 부정**: NVIDIA 리서치 페이지가 직접 경고합니다 — "3D-Guided"는
"신경망이 3D 월드 전체를 다시 계산한다"는 뜻이 아니라, **렌더러가 만든 3D 정보(G-buffer)에
근거를 둔(renderer-grounded) 생성 방식**이라는 뜻입니다. 즉 DLSS5는 지오메트리·카메라·
애니메이션·기본 장면 구조는 여전히 게임 엔진이 렌더링하고, DLSS5는 그 위에 조명/재질
외형만 생성형으로 재해석합니다.

## 6. 이전 DLSS(4/4.5)와의 파이프라인 위치 차이

| | 기존 DLSS 1~4.5 | DLSS5 |
|---|---|---|
| 문제 유형 | 재구성(부족한 픽셀/프레임 추정) | 생성(완성된 프레임의 외형 재해석) |
| 파이프라인 위치 | 렌더링 중간(업스케일링) 또는 프레임 사이(프레임생성) | 렌더링 파이프라인 **끝단** |
| 입력 | 저해상도 프레임, 모션 벡터 | 완성된 컬러 프레임 + G-buffer + 마스크 |
| 목표 | 레퍼런스(고비용 렌더링 결과)에 근접 | 새로운 최종 외형 자체를 생성 |

  미공개**(back2gaming 리뷰가 명시적으로 확인, 등급 b).
- RTX 40 시리즈가 안 되는 구체적 기술 사유(단순 "5세대 Tensor Core 타겟"이라는 마케팅
  문구 외에 아키텍처적 근거): 미확인(등급 c).
- Diffusion step 수, 정확한 loss function, 학습 데이터셋 구성: 리서치 페이지 요약
